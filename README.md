# Fitness & Workout Planner 🏋️

A responsive web application designed to help users plan workout routines, log completed exercises, and track their fitness progress through an interactive dashboard.

## About the Project

The Fitness & Workout Planner aims to make workout management easier by allowing users to organize their exercise routines, record their workouts, and monitor their physical activity over time.

This project is being developed as part of **SW 302 – User Interface Development** at Zewail City for Science, Technology and Innovation, Fall 2026.

## Planned Features

- **Workout Dashboard:** View workout statistics and progress visualizations.
- **Exercise Library:** Browse, search, and filter exercises.
- **Exercise Details:** Explore exercise instructions, target muscles, and safety tips.
- **Routine Builder:** Create and organize personalized workout routines.
- **Workout Logging:** Record completed exercises, sets, and repetitions.
- **Responsive Design:** Access the application on desktop and mobile devices.
